# Pride of Leo — Squled Studios

Демонстрационный прототип слота. Откройте `index.html` в современном браузере: графика, стили, скрипты и шрифты встроены; интернет не нужен. Поддерживаются компьютер и мобильные устройства; полноэкранный режим зависит от браузера. Звук запускается после взаимодействия пользователя; его можно отключить в настройках.

## Что обновлено
- Заставка, стартовый экран, вращающееся солнце и анимированная атмосфера.
- Эффекты выигрышей, scatter, sticky Wild и множителей, переходы и экраны начала и конца фриспинов.
- Панель управления, окна, подтверждение покупки и адаптация длинных сумм.
- Обновлённая типографика и процедурное музыкальное сопровождение Web Audio. Основа иллюстраций символов сохранена из исходного прототипа; полностью перерисованными они не являются.
- Игровая механика и параметры математической модели не менялись. Представленный RTP — заявленное значение прототипа, а не результат независимой проверки. Вспомогательная приблизительная симуляция 100 000 спинов дала около 99,3%, что расходится с заявленными 96,2%; скрипт упрощает игровой цикл и не является сертификационным тестом. Необходима отдельная проверка точного RTP.

## Оптимизация и мобильная версия
- Оптимизированы изображения символов, размытие при вращении и анимации; снижена нагрузка на рендеринг.
- Для устройств с сенсорным управлением или ограниченными ресурсами автоматически включается облегчённый режим. Его также можно включить через `?lite=1`.
- Добавлены портретная и альбомная мобильные компоновки, учёт безопасных отступов экрана и логотип над барабанами в портретной ориентации. Долгое нажатие на кнопку вращения включает турбо.
- Полноэкранный режим запрашивается при первом касании, если браузер поддерживает его.

## Публикация (GitHub Pages)
1. Загрузите содержимое этой папки в корень репозитория, включая `index.html`.
2. В настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки и папку `/ (root)`.
3. После публикации откройте адрес, показанный в настройках Pages. Игра также запускается локально открытием `index.html`.

## Состав и сборка
- `index.html` — автономная сборка.
- `src/` — разметка, стили, логика, фон и звук; `math.js` — параметры игры.
- `assets/` — изображения, шрифты, GSAP; `tools/` — вспомогательная обработка ресурсов; `sim.js` — вспомогательный скрипт моделирования.
- Пересборка: Python 3 и Pillow, затем `python3 build.py` из папки проекта. Команда перезапишет `index.html`. Для генерации шрифтов дополнительно используется fontTools; для отдельных инструментов обработки графики — NumPy и OpenCV. Для обычной сборки они не нужны.

## Шрифты и звук
Все шрифты распространяются по SIL Open Font License 1.1, включая возможность коммерческого использования при соблюдении условий лицензии. Полный текст и сведения об авторах: `assets/fonts/LICENSES/`. Исходные файлы: `assets/fonts/src/`.
- [Cinzel Decorative](https://github.com/google/fonts/tree/main/ofl/cinzeldecorative) — OFL 1.1, Reserved Font Name «Cinzel»; встроены неизменённые TTF.
- [Alegreya SC](https://github.com/google/fonts/tree/main/ofl/alegreyasc) — OFL 1.1; встроены WOFF-подмножества.
- [Oswald](https://github.com/google/fonts/tree/main/ofl/oswald) — OFL 1.1; встроено WOFF-подмножество.
- [Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat) — OFL 1.1; встроено WOFF-подмножество.

Музыка и звуковые эффекты синтезируются в `src/audio.js`; сторонние аудиозаписи не используются. GSAP распространяется по собственной лицензии: https://gsap.com/standard-license/ — перед коммерческим применением проверьте условия.

## Ограничения
Это не сертифицированная игра для реальных денег. Для запуска необходимы независимая проверка математики и ГСЧ, безопасность и соответствие требованиям юрисдикции. На системах с программным WebGL анимированный фон заменяется статичным; производительность зависит от устройства и браузера.
